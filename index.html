One-Line SDK for Seamless Integration

Integrate Quantix with a single script tag or npm package. The SDK automatically captures pageviews, clicks, and custom events. It works out of the box with zero configuration [5]. This reduces setup time and complexity for engineering teams.

  • Under 4KB gzipped for minimal page load impact [5]
  • Zero-config autocapture simplifies event tracking [5]
  • TypeScript-first API ensures type safety and developer experience
// Install: npm i @quantix/sdk

import { Quantix } from '@quantix/sdk'

const qx = new Quantix({
  apiKey: 'qx_live_k8x2...',
  autocapture: true,
  sessionReplay: true,
})

// Track custom events
qx.track('checkout', {
  value: 49.99,
  plan: 'pro'
})
